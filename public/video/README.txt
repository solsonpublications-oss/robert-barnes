DROP-IN INSTRUCTIONS
=====================

1. Queen Pin trailer video:
   Copy 'R. Ray Barnes Queen Pin Video Trailer.mp4' into this folder and rename it to:
   queen-pin-trailer.mp4
   The site plays it automatically at the #trailer section.

2. Author logo:
   Copy the author's logo jpg into public/images/ and rename it to:
   barnes-logo.jpg
   It appears automatically in the navbar and footer.

3. Award photographs (award-emmy.jpg / award-eclipse.jpg):
   Copy them into public/images/awards/ and rename to:
   award-emmy.jpg     -> shown in the "Michigan Regional Emmy Award" card
   award-eclipse.jpg  -> shown in the "8th Annual Eclipse Award" card
   (the names emmy.jpg / eclipse.jpg are also recognized)
   Each photo appears inside a gold frame with a WINNER badge; while a photo
   is not present, its elegant gold medallion is shown instead.

NOTES
-----
- Dev mode (bun run dev): new files are picked up — just refresh the page.
- Production (bun run start): refresh the page after dropping files; the site
  serves them instantly, no restart needed.
- Supported formats: jpg / png / webp for images, mp4 for the trailer.
